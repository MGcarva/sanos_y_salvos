2. Flujo de creación de un reporte

sequenceDiagram actor U as Usuario participant FE as Frontend :3000 participant BFF as BFF :9090 participant MS as ms-mascotas :8082 participant MQ as RabbitMQ participant GEO as ms-geolocalizacion :8083 participant COINC as ms-coincidencias :8084 participant DB as PostgreSQL participant S3 as MinIO U->>FE: Completa formulario + foto FE->>BFF: POST /api/reportes (multipart) BFF->>MS: Reenvía datos + foto MS->>S3: Sube foto → URL pública MS->>DB: INSERT reporte (JPA) MS->>MQ: Publica evento "reporte.nuevo" BFF->>BFF: Invalida caché Redis BFF-->>FE: 201 Created + datos reporte FE-->>U: Muestra confirmación MQ-->>GEO: Consume "reporte.nuevo" GEO->>DB: INSERT punto geoespacial (PostGIS) GEO->>MQ: Publica "geo.completado" MQ-->>COINC: Consume "geo.completado" COINC->>DB: Calcula coincidencias (score) COINC->>DB: INSERT coincidencias
