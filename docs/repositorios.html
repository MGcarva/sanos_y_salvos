Repositorio Principal

sanos_y_salvos — Repositorio Monorepo Principal

URL
https://github.com/mgcarva/sanos_y_salvos
Repositorio monorepo que contiene todos los componentes del sistema. Incluye frontend React, todos los microservicios Spring Boot, infraestructura Terraform AWS, Docker Compose para entorno local y documentación completa del proyecto.
  • Frontend React (directorio /frontend)
  • BFF Service — Backend For Frontend (directorio /bff-service)
  • MS-Mascotas — Microservicio de reportes (directorio /ms-mascotas)
  • MS-Geolocalizacion — Microservicio geográfico (directorio /ms-geolocalizacion)
  • MS-Coincidencias — Microservicio de matching (directorio /ms-coincidencias)
  • Auth Service — Autenticación JWT (directorio /auth-service)
  • Infraestructura Terraform AWS (archivos .tf en raíz)
  • Docker Compose para entorno local (docker-compose.yml)
  • Documentación completa (directorio /docs)

Componentes Frontend

Frontend — React SPA

Directorio
/frontend
URL
https://github.com/mgcarva/sanos_y_salvos/tree/master/frontend
React 18 Vite Leaflet Bootstrap 5 Vitest
SPA (Single Page Application) para gestión de reportes de mascotas. Incluye mapa interactivo con React-Leaflet, autenticación JWT, formulario de reporte en 3 pasos, visualización de coincidencias y chat con el asistente Amigo (Claude AI). Empaquetado como componente NPM estándar con package.json.

Componentes Backend — Microservicios

BFF Service — Backend For Frontend (API Gateway)

Directorio
/bff-service
URL
https://github.com/mgcarva/sanos_y_salvos/tree/master/bff-service
Spring Boot 3.2.5 WebFlux Resilience4j Puerto 9090
API Gateway único para el frontend. Implementa los patrones Proxy, Circuit Breaker y Facade. Orquesta las llamadas a los microservicios internos y valida tokens JWT. Expone Swagger UI en /swagger-ui.html.

Auth Service — Microservicio de Autenticación

Directorio
/auth-service
URL
https://github.com/mgcarva/sanos_y_salvos/tree/master/auth-service
Spring Boot 3.2.5 Spring Security JJWT Redis PostgreSQL Puerto 8091
Microservicio de autenticación y gestión de usuarios. Genera tokens JWT de acceso y refresco. Usa Redis para caché de sesiones y rate limiting. Soporta roles USER, REFUGIO y ADMIN. 31 pruebas unitarias con 92% de cobertura en clases de negocio.

MS-Mascotas — Microservicio de Reportes

Directorio
/ms-mascotas
URL
https://github.com/mgcarva/sanos_y_salvos/tree/master/ms-mascotas
Spring Boot 3.2.5 Spring AMQP MinIO PostgreSQL/JPA Puerto 8092
Microservicio de gestión de reportes de mascotas. Implementa el patrón Factory Method para crear reportes de tipo PERDIDO/ENCONTRADO, y el patrón Observer para publicar eventos en RabbitMQ. Almacena fotos en MinIO (S3-compatible). 13 pruebas unitarias.

MS-Geolocalizacion — Microservicio Geográfico

Directorio
/ms-geolocalizacion
URL
https://github.com/mgcarva/sanos_y_salvos/tree/master/ms-geolocalizacion
Spring Boot 3.2.5 PostGIS Hibernate Spatial RabbitMQ Puerto 8093
Microservicio de procesamiento geográfico. Genera clusters y mapas de calor usando PostGIS con extensión ST_DWithin. Consume eventos de RabbitMQ (Observer) y aplica algoritmo K-means (Strategy). 5 pruebas unitarias con 100% de cobertura.

MS-Coincidencias — Microservicio de Matching

Directorio
/ms-coincidencias
URL
https://github.com/mgcarva/sanos_y_salvos/tree/master/ms-coincidencias
Spring Boot 3.2.5 FuzzyWuzzy RabbitMQ PostgreSQL/JPA Puerto 8094
Microservicio de matching entre mascotas perdidas y encontradas. Usa FuzzyWuzzy para similitud de texto y un sistema de scoring multi-criterio (raza 30%, tamaño 20%, color 10%, geolocalización 12%). Consume eventos de RabbitMQ. 19 pruebas unitarias con 98-99% de cobertura.
